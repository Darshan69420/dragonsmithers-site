Trail Window: weather-window planner

  • Ranks every daylight window in the next five days for a hike, ride or run by rain, wind and feels-like penalties, and shows the scoring math.
  • Parses GPX files in the browser and forecasts conditions at each checkpoint for the hour you'd reach it.
  • The AI trail briefing runs behind a locked-down Cloudflare Worker: server-side API key, CORS allowlist, strict input validation, rate limiting, and a template fallback.
  • Covered by unit tests and Playwright responsive checks at 390, 768 and 1280 px.
